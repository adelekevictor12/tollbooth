This portal is the developer-facing half of that story — and it stays automatically in sync as the API evolves.

## Calling the API through Tollbooth

SDKs here talk to the API directly. To call it the metered way — the flow AI agents use on the marketplace — register an agent, buy a credit pack via PayPal, and send requests through the Tollbooth gateway with your `x-api-key`:

```bash
curl -X POST https://tollbooth-gljd.onrender.com/api/gw/sentimentscan/sentiment \
  -H "Content-Type: application/json" \
  -H "x-api-key: tbk_..." \
  -d '{"text": "I absolutely love this product!"}'
```

Every successful call is billed from the agent's balance ($0.02 each); failed calls are never billed.
